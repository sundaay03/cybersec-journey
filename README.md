How me to learn cyber security

hallo everyone, i'm sandi and i'm an informatics student at Sultan Ageng Tirtayasa University.
and now i will be learning step by step about cyber security

  My profound interest in cyber security is deeply rooted in my academic and practical exploration of computer network architectures and the Internet of Things (IoT). I am accustomed to dissecting how systems operate—from configuring complex routing protocols like OSPF and BGP in Cisco Packet Tracer to designing hardware automation and micro-controller architectures using ESP32.
  The process of designing and deploying these infrastructures has highlighted a critical reality: the more integrated a system becomes, the broader its vulnerability surface. I realize that knowing how to build networks or IoT devices is merely the first step. Understanding how to secure them from potential exploitation is the true key to future technological resilience. This realization drives my passion to deepen my knowledge in cyber security, bridging my foundational programming skills in Python and data structures with advanced infrastructure defense analysis.
  Beyond my technical background, I bring a strong track record of organizational leadership. My experience as a board member in the Informatics Student Association (Himpunan Mahasiswa Informatika)—specifically in managing event operations and external sponsorships—alongside my role as a Google Student Ambassador, has honed my skills in strategic communication, project management, and cross-disciplinary teamwork. I firmly believe that cyber security goes beyond technical hard skills; it requires the collaborative soft skills necessary to respond to threats, develop security policies, and educate the broader community.
  If given the opportunity to join TISS, I am fully committed to proactively learning, engaging in technical discussions, and sharing insights with fellow members. I look forward to contributing directly to the community's initiatives, whether through research, security tool development, or cyber security awareness campaigns.
